New to Town | App Icon Asset Kit

These icons are vector recreations of the "Selected Design" from the supplied screenshot. The source screenshot was a rendered mockup, not an original design file, so small differences in bevel/texture are possible.

Production app asset:
- NewToTown_AppIcon_Master.svg  : Editable scalable vector with full-bleed square background.
- NewToTown_AppIcon_4096.png   : Large square production master, 4096 x 4096 px.
- NewToTown_AppIcon_1024.png   : Standard 1024 x 1024 px square export.

Rounded presentation asset:
- NewToTown_Selected_Design_Rounded.svg      : Scalable visual replica with transparent rounded corners.
- NewToTown_Selected_Design_Rounded_4096.png : 4096 x 4096 px PNG, transparent outside the rounded icon.

Standalone lettermark:
- NewToTown_N_Transparent.svg      : Scalable ivory 'N' on a transparent background.
- NewToTown_N_Transparent_4096.png : High-res transparent version of the N.

Colors:
- Ivory monogram: #FAF5EF
- Sage gradient: #ADB296 (top), #A8AD8F (middle), #9FA587 (bottom)

Developer note:
For Apple App Store / iOS app icon production, use the square full-bleed master. Do not preround corners or add a drop shadow; iOS applies its own shape mask. The selected rounded design is provided for design presentations and other use cases.

The SVG files remain crisp at any resolution.
